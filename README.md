📱 Mobile Sales Data Analysis & Power BI Dashboard
📌 Project Overview

This project analyzes mobile phone sales data to understand sales performance, customer purchasing patterns, product performance, payment preferences, and regional trends.

The project uses Power BI, Excel, Power Query, and DAX to clean, analyze, visualize, and transform raw mobile sales data into an interactive business intelligence dashboard.

The goal is to provide a clear view of sales performance and identify patterns that can support data-driven business decisions.

🎯 Business Objective

The primary objective of this project is to analyze mobile sales data and answer key business questions such as:

Which mobile brands and models generate the highest sales?
How are sales performing over time?
Which cities or regions generate the most revenue?
Which payment methods are most frequently used?
Which mobile categories or models perform best?
What are the major customer purchasing patterns?
How does sales performance vary across different periods?

🔄 Data Analysis Process
1. Data Collection

The project uses a mobile sales dataset containing transaction-level information such as:

Mobile brand
Mobile model
Sales amount
Quantity
Customer information
Location
Payment method
Transaction date
Other relevant sales attributes

2. Data Cleaning & Transformation

The dataset was prepared for analysis by:

Identifying and handling missing values
Removing duplicate records
Validating data types
Standardizing categorical fields
Transforming date-related fields
Creating calculated columns where required
Preparing the dataset for Power BI analysis
3. Exploratory Data Analysis

The analysis focuses on:

Overall sales performance
Brand and model performance
Monthly sales trends
Regional/city-level sales
Payment method analysis
Quantity sold
Customer purchasing behavior

4. Power BI Dashboard

An interactive Power BI dashboard was developed to provide a consolidated view of mobile sales performance.

Users can interact with the dashboard using filters and slicers to analyze sales from different perspectives.

📊 Key KPIs

The dashboard tracks important sales metrics such as:

Total Sales
Total Quantity Sold
Total Transactions
Average Sales
Total Customers
Sales by Brand
Sales by Model
Sales by Region/City
